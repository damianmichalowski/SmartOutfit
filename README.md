# SmartOutfit

AI-powered virtual styling demo for online fashion stores.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Demo Flow

Click **Start Demo** to run the guided "Business Meeting Outfit" presentation:

1. Select beige business jacket from virtual wardrobe
2. Add black tailored trousers
3. Complete outfit with leather loafers
4. Ask AI Stylist for a business meeting recommendation
5. Apply AI suggestion (adds shirt + watch)
6. Save outfit as "Business Meeting Look"
7. Add full look to cart

Demo controls: **Next / Previous / Pause / Resume / Reset**

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- Local state only (no backend, no real AI API)
